# 长平之战人物文生图提示词 v0.1

> 以**长平之战（前 260 年）**为例，供豆包生成该役主要历史人物的写实 2D 立绘。风格流程与《[人物立绘文生图提示词 v0.1](人物立绘文生图提示词_v0.1.md)》完全一致；甲胄兵器考据引用《[战国军事美术素材参考 v0.2](战国军事美术素材参考_v0.2.md)》，不做通俗演绎造型（"铁鹰锐士"等小说名目不使用）。

## 1. 风格一致性流程（与 v0.1 提示词文档相同，照做）

1. 11 张在**同一豆包对话**内连续生成，每条都完整粘贴 §2 主风格块。
2. 先跑**白起**作为基准图；满意后其余 10 张全部上传该基准图垫图（角色/风格参考，权重调高）。
3. 固定：同一模型同一写实档位、4:3 半身胸像、左上方柔和侧光、同一 seed（支持则填）。
4. 只有人物身份/年龄/服色/表情可变，背景、光质、笔触词汇逐字复用。
5. 若基准图更换，全部重跑，不混用两套风格。
6. 本批与既有《人物立绘文生图提示词 v0.1》的 7 张共用同一主风格块；如要两批完全统一，以**同一基准图**垫图。

## 2. 主风格块（每条原样粘贴）

```
中国战国时期（公元前475-221年）写实历史人物半身肖像，电影级关键帧质感，写实人体比例与真实年龄感，低饱和大地色系，画面以土黄#c8a96a、墨黑#2a2620、朱红#a8412b三色为主，做旧青铜与黑漆皮札甲，甲片用丝带横排编缀，新铸兵器呈赤金色金属高光（非青绿铜锈），髹漆甲片黑底朱边，布料与皮革高细节纹理，淡墨晕染暗背景，左上方柔和侧光，沉稳肃杀的战争氛围，浅景深，胸像取景、人物居中，笔触写实厚重，整体色调统一
```

## 3. 统一负向提示（每条都附）

```
Q版，卡通，动漫，二次元，大头比例，科幻，全息，霓虹灯，高饱和色，MOBA游戏宣传画风，血腥断肢，现代物品，文字水印，手指畸形，明清服饰，明清棉甲，戏曲靠甲，板甲，锁子甲，高桥马鞍，马镫，环首刀，绿锈青铜器，头盔戴在秦军头上，每张图画风不同
```

### 3.1 阵营造型硬约束（写 prompt 时已内置，返工补述用）

- **秦军**：科头无胄、头发束**偏右椎髻**或将冠；深色札甲（白起可用秦将军俑式彩色鱼鳞札甲，仅此一人）；佩秦式细长剑。来源：素材参考 §4.4/§5.2。
- **赵军**：武将皮札甲 + 皮胄可戴；胡服元素（短衣窄袖、革靴）给边骑气质人物；中原步兵体系仍用深衣外罩甲。
- **通用**：青铜兵器画**金色**不画绿锈；甲是**札甲**，无板甲/锁子甲；无马镫无高桥鞍（本批为半身像，如出骑马版本必须遵守）。

## 7. 出图后自检

| 检查项 | 标准 | 不通过处理 |
|---|---|---|
| 秦军无盔 | 白起/王龁/秦王露椎髻或戴冠，**绝无兜鍪**（素材参考 §4.4） | 重跑，负向提示加重"秦军戴头盔" |
| 甲制 | 全部札甲编缀，无板甲/锁子甲/山文甲 | 重跑并写明"皮甲片丝带编缀" |
| 兵器 | 金色青铜、无绿锈、无环首刀 | 重跑 |
| 阵营区分 | 赵军赭石旗/甲、秦军朱红黑甲，11 张并排一眼可分 | 调整垫图权重或重跑 |
| 风格统一 | 与基准图同一光场、同一色温和笔触 | 以漂移最小者为新基准全部重垫 |
| 三基色覆盖 | 土黄/墨黑/朱红 ≥80%，亮金仅甲片高光（<3%） | 重跑，强调低饱和大地色 |
| 时代感 | 无明清服饰、无戏曲脸谱化 | 重跑 |

## 8. 演绎边界备注

- "秦尚黑"正式定于统一之后（素材参考 §6），本批秦王/秦军黑袍色是**美术演绎**，与游戏三基色一致，设定集需标注。
- 人物面部无传世可靠画像，年龄/神态据《史记·白起王翦列传》《史记·廉颇蔺相如列传》的记载气质设计，属合理推演而非复原。
