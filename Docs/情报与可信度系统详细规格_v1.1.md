## 1. 概述

本系统负责游戏中所有情报的生成、传递、评估与失效。包括：

- 玩家对敌方态势的认知（基于己方斥候/间谍/降兵/截获文书）
- 敌方 AI 对玩家态势的认知（基于 AI 斥候/间谍/降兵/截获文书）
- 双方"诡道技能"对情报系统的干扰（欺骗类技能注入假情报、反制类技能识破假情报）
- 情报在 UI 上的呈现方式（可信度标签、情报年龄、来源追溯）

**核心约束：**

玩家和 AI 在情报层面使用完全相同的规则引擎。AI 没有"全图透视"，玩家也没有"上帝视角"。唯一区别是：AI 的决策频率由系统控制（每帧可跑），玩家的决策由人的反应速度控制。

**系统边界：** 本系统只产生与维护"认知层"对象（情报、可信度、信任度），不持有 UI 以外的特殊权限。真实战场状态（实际兵力、真实位置等）对双方均不可直接读取，只能通过满足条件的侦查采样间接获得。

## 2. 情报来源分类

| 来源类型 | 默认可信度基值 | 获取方式 | 是否可被欺骗技能伪造/干扰 |
| --- | --- | --- | --- |
| 斥候目视 | 65% | 部署斥候单位到目标区域，停留时间越长，单次目击采样越多 | ✅ 是（如"减灶"使炊烟数量与兵力不符） |
| 降兵/乡民口供 | 35% | 战斗后俘获、或村庄/乡民互动 | ✅ 是（敌方可通过"伪传军令"让降兵携带假信息） |
| 截获文书 | 80% | 斥候/骑兵袭击敌方信使或辎重队 | ✅ 是（敌方可通过"伪传军令"伪造文书） |
| 敌方技能暴露 | 75% | 敌方释放某些技能时必然在特定区域留下痕迹（如"火攻粮道"的浓烟）。**火攻在切片即实现并产出本条情报**（见 §9） | ❌ 否（技能本身的视觉/听觉效果是真实的；该情报由系统在起火瞬间生成，无需斥候采样，但只有对起火点有视野的一方收到） |
| 长期规律归纳 | 由历史数据计算（见 §3.1，**生成时快照**，见 INTEL-10） | 多轮斥候目击同一区域的时间序列归纳 | ✅ 是（敌方可通过持续一致的假情报诱导规律归纳错误） |

## 3. 可信度计算公式

系统存在**两层**可信度量，后续所有章节共用此定义：

| 层 | 量 | 值域 | 含义 |
| --- | --- | --- | --- |
| 情报层 | 情报可信度（单条 / 综合） | 0–100% | "这条/这批情报本身有多可靠"，随情报年龄衰减 |
| 信念层 | AI 主题信任度（trust bucket） | 0–1 | "AI 对某一主题长期积累的确信程度"，跨多条情报更新（见 §5） |

玩家不使用信任度桶，但玩家 UI 会展示同主题情报的综合可信度（与 AI 同公式），双方在情报层完全对等。

### 3.1 单条情报的可信度（瞬时值）

分两步计算。

**第一步：新鲜可信度（情报刚产生时）**

```text
fresh = min(100, 基值 + 目击单位数修正 + 持续目击时长修正)
```

**第二步：年龄衰减（向地板线性收敛，15 分钟到达并过期）**

```text
floor      = 基值 × 30%
ageFactor  = max(0, 1 − age_minutes / 15)
可信度     = floor + (fresh − floor) × ageFactor

age_minutes ≥ 15 → 情报过期（status = expired），移出活跃情报池，不再参与综合判断
```

**参数定义：**

| 参数 | 计算方式 | 取值范围 | 说明 |
| --- | --- | --- | --- |
| 基值 | 按 §2 来源类型取值 | 35–80% | 固定。"长期规律归纳"的基值 = 该主题历史采样结论的一致率（结论一致的采样占比），clamp 到 40–75% |
| 目击单位数修正 | +2% × min(目击单位数, 10) | 0–20% | 看到同一目标的斥候越多，越可信；超过 10 个后边际不再增加 |
| 持续目击时长修正 | +1% × min(连续目击分钟数, 20) | 0–20% | 斥候盯住一个区域越久，采样越多；超过 20 分钟不再增加 |
| 情报年龄衰减 | 按上式向 floor 收敛 | — | 任何来源都严格在第 15 分钟时衰减至"基值×30%"并过期；基值越低的来源绝对衰减越慢、相对比例一致 |
| 敌方欺骗技能干扰 | **不进入本公式** | — | 欺骗技能篡改的是情报**载荷内容**（兵力估算值等），不直接削减可信度数字——受骗方在识破前无从感知欺骗。机制详见 §4 |

**情报条目生成粒度（v1.1 明确，真源 INTEL-09）：**

- 同一斥候对同一区域、同一主题的**一次连续侦查只产生 1 条情报**；持续目击时长修正（INTEL-03）在该条上持续累积，斥候离开区域或侦查中断后再次侦查才产生新条目。
- 不同斥候的侦查各自产生独立条目；"最近 3 条情报"（TRUST-03）因此通常需要多个斥候或多次侦查任务才能积累，而非一次盯梢刷出多条。
- `pattern_inference`（规律归纳）条目的可信度在**生成时按当时历史一致率快照**（clamp 40–75%，真源 INTEL-10），此后只走上文年龄衰减，不随后续新采样回溯修改；新采样产生新的归纳条目。

> 勘误说明：旧稿公式为"… − 2%/分钟 − 敌方欺骗技能干扰"，与参数表"基值×0.5/×1.5"自相矛盾（×1.5 无法做减法），且固定 −2%/分钟会使低基值来源在 15 分钟内减为负数。现统一为本节公式。

### 3.2 综合判断的可信度（决策用）

当玩家或 AI 基于多条情报做出决策时（如"敌人是不是空虚了？"），系统对同一主题下**所有未过期、未被标记为伪造**的情报做加权汇总：

```text
综合可信度 = (∑(情报可信度 × 来源权重)) / ∑来源权重
```

**来源权重：**

| 来源 | 权重 |
| --- | --- |
| 斥候目视 | 1.0 |
| 截获文书 | 1.2（敌方无意中泄露的真实信息，权重略高） |
| 降兵口供 | 0.6 |
| 敌方技能暴露 | 1.0 |
| 长期规律归纳 | 0.9（有归纳价值，但可被持续一致的假情报诱导，略低于目视） |

**可信度分档（情报层阈值，玩家 UI 与 AI 决策共用）：**

| 综合可信度 | 档位 | AI 行为 |
| --- | --- | --- |
| ≥ 85% | 确信 | 可直接决策；**满足此档且对应信任桶 > 0.8 时，方可触发 §3.3 历史叙事大事件** |
| 70–84% | 可信 | 信任桶 > 0.8 时可直接决策，否则按存疑处理 |
| 50–69% | 存疑 | **强制复核**（见 §5.3），不直接做高利害决策 |
| < 50% | 不可信 | 不据此决策 |

## 4. 欺骗技能如何写入情报系统

欺骗技能的本质：**在真实战场状态与侦查采样之间插入一个"假情报对象"，篡改侦查返回的载荷内容**；可信度公式照常计算，因此假情报可以携带很高的可信度——这正是欺骗生效的方式。

欺骗效果系数为**技能配置数据**（数据驱动，新技能走配置，不硬编码）。已有技能：

| 技能 | 作用来源 | 载荷篡改 |
| --- | --- | --- |
| 减灶示弱（reduce_stove） | 斥候目视（炊烟推算兵力） | 兵力估算值 × 0.3（看到的兵力仅为实际三成） |
| 增灶示强（add_stove） | 斥候目视（炊烟推算兵力） | 兵力估算值 × 1.5（使敌方高估兵力） |
| 伪传军令（false_orders） | 截获文书 / 降兵口供 | 载荷整体伪造（内容、印信、口供均为假，无乘数） |

**施计窗口与痕迹存续（v1.1 修订，真源 DECP-02/03）：** 减灶/增灶的"施计窗口"为 90 战场秒（赵军改灶动作的完成时间）；技能结束后，假灶坑形成的炊烟**痕迹在目标区域存续 10 战场分钟【初值】**，存续期内对远观炊烟的新采样持续生效；近距 50 米清点营盘（识破路径①）看到真实营帐，在任何阶段都可识破。存续期内对同一区域重复释放不延长存续、不重置计时（DECP-08，防无缝永续）。此模型闭合了"90 秒窗口内无法完成长时目击"与"减灶典故中齐军数日见灶数递减"之间的矛盾——技能是短暂动作，留下的错误痕迹才是长期诱饵。

### 4.1 "减灶示弱"完整链路（数值闭合示例，v1.1 重写）

> **v1.1 修订要点：** 旧版示例让斥候"持续目击 8 分钟"，但假情报对象只在 90 秒施计窗口内存在（§4.2），后 6.5 分钟斥候看到的是真实炊烟，示例自相矛盾；且旧示例隐含信任桶初值 0.50，单条 75% 情报实际只能把桶推到 0.59，AI 根本不会冒进。本版按"施计窗口 + 痕迹存续"（DECP-02）与"桶预养"前提（TRUST-09）重写，全链路数值可复算。

**阶段一：预养（战役前期的常规侦查建立信任）。** 秦军本就在监视赵军西线，t=2:00–6:00 间对主题"赵军_西线兵力"收到 3 条真实情报（更新量按 §5.2，数值四舍五入）：

```text
t=2:00 斥候目视 65%（signed +0.30，ind=0.6，time=1.0）：0.500 → 0.554
t=4:00 截获调兵文书 80%（最近 3 条含 2 种来源 ind=0.8，time=1.0）：0.554 → 0.698
t=6:00 斥候目视 64%（ind=0.8，time=1.0，signed +0.28）：0.698 → 0.765
```

（上述数值按 §5.2 逐步复算；下文凭两位小数约算为 0.77。）秦 AI 由此形成认知"赵军西线约 2000 人"，信任桶 ≈ 0.77（未决区上沿，尚未到 0.8 行动线，但已有明确倾向）。

**阶段二：施计与痕迹存续。**

1. t=10:00，赵军在 A 区域实有 2000 人，赵方释放"减灶示弱"：**施计窗口 90 战场秒**（改灶动作），完成后假灶坑的炊烟**痕迹在 A 区域存续 10 战场分钟**（DECP-02，初值可调），存续期内远观炊烟的新采样载荷 ×0.3。
2. t=11:00，秦军 1 个斥候进入 A 区域**远观**（距营盘 >50 米，未触发识破路径①），持续目击 8 分钟至 t=19:00——全程落在痕迹存续期（至 t=20:00）内，看到的炊烟始终对应篡改后载荷。情报即时回传（年龄 0），可信度按正常公式计算：

```text
fresh = 65% + 2%×1（斥候数） + 1%×8（持续分钟） = 75%
ageFactor = 1（年龄 0）
可信度 = 75%
```

3. 信任桶更新（§5.2）：最近 3 条情报为 [t=6:00 目视、t=4:00 文书、本条目视]，含 2 种来源 → ind=0.8；距该桶上次更新已 13 分钟 → time=0.5：

```text
newTrust = 0.765 + (0.75−0.5)×2 × 0.8 × 0.5 × 0.3
         = 0.765 + 0.5 × 0.8 × 0.5 × 0.3
         = 0.765 + 0.06 = 0.825（约 0.83）
```

4. 秦方拿到的情报为"赵军兵力 = 600（实际 2000 ×0.3），可信度 75%"。75% 落入"可信"档（70–84%），信任桶 0.825 > 0.8，**双条件同时满足**（§3.2/§5.2 门控），秦 AI 判定"赵军兵力空虚/已撤退大半"，触发轻兵冒进。

**设计说明（为什么欺骗需要"预养"）：**

- 同样一条 75% 假情报，若投到初始 0.50 的冷桶上（ind=0.6、time=0.5）：`0.50 + 0.5×0.6×0.5×0.3 = 0.545`，AI 只会起疑、复核，绝不会冒进。**减灶不是无中生有的法术，而是先让对手通过常规侦查建立起信任（桶养过 0.8），再用高可信假载荷反转其结论**——这与孙膑减灶的史实逻辑一致（庞涓本就轻视齐军，"齐军怯"是既有判断）。原型剧本应通过前期侦查节奏把秦 AI 与玩家都置于"已有关注、倾向相信"的状态，再放出减灶。
- 信任桶是对主题**当前载荷**的采信度，不区分"信空虚"与"信充实"两个方向（TRUST-09）：桶高时，AI 相信的是**最新可信载荷**；600 与此前认知的 2000 之间的落差由 AI 自行解释为"赵军正在撤退"，落差本身不触发识破（识破只走 §4.3 两条硬路径）。
- 秦方看到的高可信度不是 bug——情报来自一次合规、持续的目视侦查，采样过程无可挑剔，错的是被篡改的载荷。这就是"兵者诡道"。
- **反例（识破）：** 若该斥候在痕迹存续期内进入假情报生成点 50 米内清点营盘，看到 2000 人营帐与炊烟推算的 600 人必然矛盾，立即触发 §4.3 路径①识破（与看了多久无关）；或秦方另外拿到截获文书等异质信源、估算差异 ≥50%，走路径②。

### 4.2 假情报对象与痕迹的生命周期（v1.1 修订）

- **施计窗口**：假情报对象（减灶/增灶的改灶效果）在技能施计窗口（90 战场秒）内生成于目标区域。
- **痕迹存续**：施计窗口结束后，篡改效果以"假灶坑炊烟"形式作为区域**痕迹**继续存续 10 战场分钟（DECP-02/03，初值），存续期内对进入区域的**远观新采样**持续生效；近距 50 米清点营盘（识破路径①）任何阶段都看到真实状态。
- **不叠加刷新**：同一区域同源痕迹仍在存续期内时重复释放，不延长存续、不重置计时（DECP-08），防止减灶无缝永续。
- **痕迹消散与已带回情报**：痕迹存续期满后，之后的新远观采样看到真实炊烟；**但已经被斥候带回的假情报条目不会自动消失**，它继续留在接收方情报池中按 §3.1 年龄规则存活（最长 15 分钟），直到过期或被识破——受骗方脑中的错误认知不随施计方收技或痕迹消散而纠正。

### 4.3 识破条件（两种，任一满足即触发）

1. **近距实体目击**：斥候进入假情报生成点 50 米内（约一次贴脸侦查），采样来源由"远观炊烟"升级为"直接清点营帐/人员/器械"。炊烟可伪减、营盘规模难伪，近距计数与炊烟推算值必然矛盾。
2. **异质独立信源交叉**：同一主题出现 ≥ 3 个相互独立、且包含 ≥ 2 种**不同来源类型**的情报（例如：斥候炊烟估算 ×0.3 vs 截获调兵文书的实数 vs 降兵口供），估算值之间最大差异 ≥ 50%（600 与 2000 的差异为 233%，触发）。

> 勘误说明：旧稿写"3 个斥候在不同方向侦查即可识破"。减灶是**区域一致效果**，3 个斥候从任何方向看到的炊烟假数据都完全相同，不构成矛盾——同质信源再多也无法识破，这恰是减灶的威胁所在。故改为"异质信源"，且同一欺骗技能生成的多条情报在识破前**不计为相互独立**（持续一致的假情报同样能污染 §2 的"长期规律归纳"）。

**识破后果：**

- 该情报 `status = flagged_fake`，面板可信度瞬间降为 **15%** 并标注"疑似伪造"，保留在时间线中可回溯，但**不再参与 §3.2 综合可信度计算**（从决策聚合中剔除）。
- 对应 AI 信任桶立即置为 **0.2**（高度怀疑档，见 §5.2），并强制对该主题发起一次**识破型复核（弱复核，TRUST-09）**：已在执行中的命令保持惯性（行军、接战中的部队不冻结、不召回），只冻结**新的**高利害决策（不发起新进攻/追击/撤退），同时派出复核斥候；兵力空闲时表现为原地戒备。其约束弱于 §5.3 的存疑型复核——识破往往发生在敌方已按假情报行动之后，强制全体静止会造成冲锋途中冻结的观感灾难。

## 5. AI信任度系统（AI 侧的"信念层"）

> 审校意见要求重写信任度算法。本规格采用分桶 + 双向更新设计。

### 5.1 信任度分桶存储

不是全局标量，而是按情报主题分桶：

```text
trustBuckets = {
    "赵军_西线兵力": 0.65,
    "秦军_粮道安全": 0.80,
    "魏韩_是否出兵": 0.50,
    ...
}
```

每个桶独立更新，初值 0.50（中立），取值区间 [0.10, 0.95]。

### 5.2 信任度更新规则

每次新情报到达时，先把情报可信度由 0–100% 归一化为 0–1（除以 100），再做**有符号**更新：

```text
independence = 信源独立因子        // 0.6 / 0.8 / 1.0
timeFactor   = 时间衰减因子        // 1.0 或 0.5
signed       = (情报可信度 − 0.5) × 2                       // −1 … +1，以 0.5 为中点
newTrust     = clamp(旧信任度 + signed × independence × timeFactor × 0.3, 0.10, 0.95)
```

| 因子 | 计算 | 说明 |
| --- | --- | --- |
| 情报可信度 | §3.1/§3.2 结果 ÷100 | 0–1；高于 0.5 增强信任，低于 0.5 削弱信任（双向） |
| 信源独立因子 | 该主题最近 3 条情报（含本次）中，不同 `source_type` 的数量：1 种 → 0.6；2 种 → 0.8；≥ 3 种 → 1.0 | 多类型信源交叉才有分量；同一欺骗技能产出的多条情报识破前按 1 种计 |
| 时间衰减因子 | 距该桶上次更新 ≤ 2 分钟 → 1.0；> 2 分钟 → 0.5 | 陈旧主题上的更新影响力减半 |

> 勘误说明：旧稿公式为 `旧信任度 + 修正量×0.3`，修正量恒为非负——一条可信度 15% 的情报仍会**增加**信任度，信任只升不降。现改为以 0.5 为中点的有符号更新。

**算例：** 桶初值 0.50；收到 §8 样例情报（可信度 68% → 0.68）；最近 3 条含 2 种来源（0.8）；距上次更新 1 分钟（1.0）：

```text
signed   = (0.68 − 0.5) × 2 = 0.36
newTrust = 0.50 + 0.36 × 0.8 × 1.0 × 0.3 = 0.586 ≈ 0.59
```

**边界规则与情报层的联合门控：**

| 信任桶 | 标签 | 与情报层联合行为 |
| --- | --- | --- |
| < 0.30 | 高度怀疑 | 强制增派斥候复核，不据此做重大决策（无视单条情报档位） |
| 0.30–0.80 | 未决 | 即使情报达"可信"档也先复核 |
| > 0.80 | 可信 | 情报达"可信/确信"档时可直接决策 |

**伪造识破处置优先于增量更新：** 一旦某情报被识破（§4.3），对应信任桶直接置 0.20，不走上述增量公式。

**桶的语义（v1.1 明确，TRUST-09）：** 信任桶是对某主题**当前载荷**的总体采信度（0–1 标量），**不是**有方向的信念——不存在"信兵力多"和"信兵力少"两个桶，也不绑定历史结论方向。桶高只表示"AI 愿意采信该主题下最新的可信情报"；当新载荷（含被技能篡改的载荷）达到可信档时，AI 直接采信当前值并自行解释变化原因（如"敌军在撤退"）。这意味着欺骗要生效，施计方必须先用常规真情报把桶养过 0.8，再让篡改载荷反转（见 §4.1 预养示例）；向冷桶（0.50）直接投放一条假情报只会引起复核。

> 关于"边缘可信度温水煮青蛙"的说明：有评审建议对 50–69% 情报设 signed 死区或强制负向更新。经复核**不采纳**——TRUST-05 门控是"桶 **且** 情报档位"的双条件，50–69% 存疑档无论桶多高都强制复核（§3.2 分档表），桶被边缘情报慢慢推高并不会绕过复核；而强制负向更新会惩罚真实但不精确的情报、破坏有符号更新的双向对称性。死区可作为调参项在切片 QA 后评估，不进 v1.1。

### 5.3 强制复核机制（v1.1 拆分两类）

当高利害决策相关情报命中以下任一条件时触发**存疑型复核（强复核，TRUST-07）**：综合可信度处于 50–69% 存疑档；或情报达 70% 但信任桶 ≤ 0.8；或信任桶 < 0.3。

1. AI 不立刻决策，在该区域额外部署 2–3 个斥候复核，耗时 30–60 秒（战场实时）。
2. 复核期间 AI 维持当前态势不变（不进攻、不撤退、不调兵），兵力空闲单位原地戒备；实现上应给复核部队可观察的状态表现（如斥候四散、步骑戒备姿态/图标），避免玩家误判为"AI 卡死"（该状态为 AI 内部行为，不向敌方暴露信任数值）。
3. 复核以新斥候带回的**新鲜情报**重新计算综合可信度与信任桶，再走 §5.2 门控决策。
4. 若复核期间原情报年龄满 15 分钟过期，则必须以新采样为唯一依据，不得沿用过期结论。

**识破型复核（弱复核，TRUST-09）：** 由 §4.3 识破（桶直接置 0.20）触发，规则不同：

1. 同样部署 2–3 个斥候、耗时 30–60 秒，但**已在执行中的命令保持惯性**——正在行军/冲锋/接战的部队继续当前动作，不冻结、不召回。
2. 只冻结**新的**高利害决策：不发起新的进攻、追击、撤退或调兵；若复核结论为假情报，部队在当前动作自然结束（接战脱离/到达目标点）后再按新决策行动。
3. 触发原因是识破往往发生在敌方已经按假情报行动之后（如已按"赵军空虚"冒进），此时全体静止既不合理也会暴露 AI 状态。

## 8. 数据规格（开发用）

### 8.1 情报对象（接收方可见字段）

```json
{
  "intel_id": "INTEL_20260909_001",
  "topic": "赵军_西线兵力",
  "source_type": "scout_visual",
  "base_credibility": 65,
  "raw_content": {
    "type": "troop_count_estimate",
    "value": 600,
    "unit": "men"
  },
  "modifiers": {
    "scout_count": 3,
    "duration_minutes": 4,
    "age_minutes": 2
  },
  "credibility_shown": 68,
  "status": "active",
  "created_at": "2026-09-09T14:32:00Z",
  "expires_at": "2026-09-09T14:47:00Z"
}
```

### 8.2 权威端附加字段（不对接收方下发）

```json
{
  "intel_id": "INTEL_20260909_001",
  "true_content": {
    "type": "troop_count_estimate",
    "value": 2000,
    "unit": "men"
  },
  "deception": {
    "is_fabricated": true,
    "fabricated_by": "player",
    "skill_id": "reduce_stove",
    "content_multiplier": 0.3,
    "detected": false
  }
}
```

### 8.3 字段说明

| 字段 | 说明 |
| --- | --- |
| `source_type` | `scout_visual` / `prisoner` / `captured_doc` / `skill_reveal` / `pattern_inference` |
| `raw_content.value` | 接收方实际看到的载荷。本例 = 2000 × 0.3 = **600**（减灶篡改后），并非真值 |
| `credibility_shown` | 接收方面板可信度（整数百分比）。本例计算：fresh = 65 + 2×3 + 1×4 = 75；floor = 19.5；ageFactor = 1 − 2/15 ≈ 0.867；shown = 19.5 + (75−19.5)×0.867 ≈ **68**。落入 50–69 存疑档，AI 须强制复核 |
| `status` | `active` / `expired`（年龄满 15 分钟）/ `flagged_fake`（识破，可信度固定 15% 且退出决策聚合） |
| `true_content` / `deception` | **权威端独占**（单机为 AI 权威侧，联网待防作弊架构定稿后绑定服务器）：真实载荷、伪造者、技能、篡改系数、是否已识破。接收方客户端永不收到这两个块；识破后仅向接收方下发 `status = flagged_fake` 与 `credibility_shown = 15` |
| `expires_at` | 恒等于 `created_at + 15 分钟` |
