## 1. 保证 7 张图风格一致的用法（重要）

文生图最大的风险是每张风格漂移。按以下顺序操作：

1. **同一会话连续生成**：7 张在豆包**同一个对话**内生成，不要新开对话；每次都完整粘贴「§2 主风格块」，不靠"保持上文风格"。
2. **先出基准图，再垫图**：先用「廉颇」或「赵轻骑」跑出一张满意的基准图；后续 6 张**上传基准图作为风格参考图（垫图/角色参考）**，prompt 仍完整粘贴，风格一致性权重调高（若有该参数）。
3. **固定参数不变**：

   | 参数 | 值 |
   |---|---|
   | 模型版本/画风 | 同一模型、同一写实风格档位（7 张不要切换） |
   | 幕僚/将领比例 | 4:3（竖构图半身像） |
   | 兵种单位比例 | 1:1（全身立绘，纯色背景便于抠图） |
   | 种子 seed | 基准图确定后记录其 seed，其余 6 张**沿用同一 seed**（豆包支持则填；不支持则靠垫图） |
   | 光影 | 统一"柔和侧光、左上方光源" |

4. **只允许变量**：人物身份、甲胄色码、姿态。其余词汇（背景、笔触、光质、镜头）逐字复用，不增不减。
5. **返工规则**：单张不合格时只重跑该张并继续垫基准图；若基准图本身换了，**全部 7 张重跑**，不混用两套风格。

## 2. 主风格块（每条 prompt 必须原样粘贴的前缀）

```
中国战国时期（公元前475-221年）写实历史人物插画，电影级关键帧质感，写实人体比例，低饱和大地色系，画面以土黄#c8a96a、墨黑#2a2620、朱红#a8412b三色为主，做旧青铜甲与漆皮札甲，布料与金属高细节纹理，淡墨晕染暗背景，左上方柔和侧光，沉稳肃杀的战争氛围，浅景深，整体色调统一，笔触写实厚重
```

## 3. 统一负向提示（每条都附）

```
Q版，卡通，动漫，二次元，大头比例，科幻，全息，霓虹灯，高饱和色，MOBA游戏宣传画风，血腥断肢，现代物品，文字水印，手指畸形，明清服饰，明清盔甲，鲜艳渐变背景，每张图画风不同
```

## 5. 出图后自检（对照基线验收）

| 检查项 | 标准 | 不通过处理 |
|---|---|---|
| 三基色覆盖率 | 土黄/墨黑/朱红覆盖画面主体 ≥80%（基线 H3） | 重新生成，prompt 中强调"低饱和大地色系" |
| 亮金占比 | 无亮金或极少（仅允许甲片微弱高光，<3%） | 负向提示加"金色光芒、华丽特效" |
| 风格统一 | 7 张并排看像同一画师、同一光场 | 以漂移最小的一张为新基准全部重垫 |
| 时代正确 | 札甲/兜鍪/胡服，无明清棉甲、无戏曲靠甲 | 负向提示已列，仍出错则写明"战国出土文物形制" |
| 兵种可辨 | 4 兵种凭武器/甲色即可区分（基线 A1） | 强化武器与色码描述重跑 |
| 单位抠图 | 兵种 4 张背景纯净、脚底无重投影 | 重跑或本地抠底，底色取 `#c8a96a` |
