## 2. 类型分布与设计意图

- 欺骗类 6（减灶/增灶/烽火/反间/声东/伪传）：核心卖点载体，全部走假情报对象机制。
- 突袭类 4（火攻/暗度/焚粮/断粮）：改变战场物理现实，其使用痕迹本身是真实信源。
- 外交/防御类 2（合纵/坚壁）：绑定幕僚在场，推动幕僚系统使用。

通用池 6 个（火攻、暗度、反间、声东、断粮、伪传）保证两国玩家"2 通用计"选择有组合深度；阵营计让赵/秦体验不对称；幕僚计把 §3.2 的人物性格推到操作层。

## 4. 与槽位/反制链的联动校验

- 赵方阵营计 2 选 1（减灶/增灶不能同场）；通用池 6 选 2，可带"反间计 + 1 欺骗计"形成攻防一体。
- 切片期通用池只有火攻可选，故切片实际配置：阵营计（减灶或增灶）+ 火攻 + 1 空通用槽 + 幕僚槽空（廉颇/赵括幕僚计二期）——槽位 UI 二期完整，切片灰显即可。
- 反间计是 GDD §2.3.2 反制链表格引用的技能；**v1.2 定案：长平战役内不实现**（改为剧本事件 CP-03）。第二阶段的处理方式为：先把 §3 的五个问题按"盲释放"路线评审定案，再决定是否进技能系统；DECP-07 描述的"指定当前生效欺骗"仍是定案前的暂定表述。
- **长平战役槽位配置（v1.2）**：实际配置＝阵营计（减灶或增灶）+ 火攻 + 1 空通用槽 + 1 空幕僚槽（廉颇/赵括的幕僚专属计仍属二期，见真源 SKILL-09 与 ADV-07）——与切片配置一致，但因幕僚已实装（ADV-07），幕僚槽在 UI 上应显示"无专属计"而非"幕僚不在场"。
