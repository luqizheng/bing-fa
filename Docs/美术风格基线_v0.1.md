## 1. 设计意图

### 1.1 核心原则

1. **信息不对称优先**。本作核心是"欺骗是否好玩"（GDD §1.1、§6 SLICE-05），所有美术决策不得削弱信息层可读性。画面服务于系统表达，而非"好看"本身。
2. **诚实游戏设计**。欺骗对象必须**事后可识别**（继承 L1 §2.2.1）——不能让玩家被骗了还不知道。本条与"美术精致"冲突时，美术让位。
3. **历史感 ≠ 考据堆砌**。本作定位是"即时战略 · 战争欺骗"，历史氛围为底色，不是"历史教育软件"。视觉语言以**美学方向**为主，不要求每件装备都 1:1 复刻出土文物。
4. **MVP 与终版分层**。本规范为 MVP 与终版共用一份，但 §4 地图、§5 单位模型按 GDD §6 推到第四阶段——MVP 阶段允许用低保真占位（§8）。

### 1.2 可证伪假设

| ID | 假设 | 验证方式 | 失败信号 |
|---|---|---|---|
| **H1** | 仿古帛画/竹简质感能传达战国历史感，且不干扰信息层可读性 | 垂直切片测试：玩家口述"我感觉在玩战国题材"且能描述信任桶 | 玩家说"画面太杂看不出信息"或"没有战国感" |
| **H2** | MVP 低保真占位（cube + 色码 + 战旗 billboard）足够支撑玩法验证 | 10 名测试玩家 ≥7 人完成核心循环（庙算→战役→识破） | 玩家因"画面简陋"流失，或无法区分兵种/阵营 |
| **H3** | 调色板三基色（土黄/墨黑/朱红）覆盖 ≥80% 画面，能保证视觉统一 | 截屏色域统计 | 画面被其他色相割裂 |

| 色名 | 十六进制 | 唯一允许用途 |
|---|---|---|
| **亮金** | `#d4af37` | 仅用于"确信"描边（真源 INTEL-07 ≥85%）与高光 |

### 2.4 色温规则

- **暖色 = 玩家视野与 UI 焦点**（土黄/赭石/朱红主导）
- **冷色 = 敌方/迷雾/低信任**（深蓝/灰青/深墨绿）
- **中性 = 文字与轮廓**（墨黑 + 浅灰）

## 3. UI 元素风格（继承 GDD §4.3 细化）

GDD §4.3 已定 UI 元素方向："竹简展开""虎符""青铜纹"。本规范细化应用规则。

### 3.1 竹简展开

- **应用位置**：顶部导航、情报看板、幕僚建议面板
- **纹理**：纸面颗粒 + 边缘不规则卷曲（参考出土竹简）
- **排版**：可选横排（信息密度高时）或竖排（仪式感场景，如开篇叙事）

### 3.2 虎符

- **应用位置**：命令/技能释放按钮
- **交互**：半符旋转 600ms → 双符契合 = 绿色脉冲（确认）；单符 = 灰色空转（取消）
- **考据**：参考陕西博物馆藏战国虎符实物，仅取其形态特征（左右两半相合），不要求纹样一致

### 3.3 青铜纹

- **应用位置**：分割线、边框、加载动画、阵营徽记
- **纹样**：饕餮纹、夔龙纹简化线稿（几何化、不写实）
- **范围限制**：仅 UI 使用，**不进入战场 3D 模型**

## 4. 地图风格

### 4.1 终版路线图（§6 第四阶段）

- **方向**：水墨地形图，山脉以中国传统山水画表现（GDD §4.3）
- **数据基础**：基于历史地理（赵国太行山、秦国函谷关真实地形，GDD §5.1）
- **渲染管线预案**：距离场 + 笔触纹理 + 半透明晕染（细节待路线图第四阶段定）

### 4.2 MVP 阶段（当前，本规范约束）

- **几何**：低保真平面（flat polygons），顶点高度数据保留供后续水墨化
- **填色**：墨黑轮廓 + 土黄填充（地形）
- **区域标识**：地块填色区分（赵控制 = 赭石，秦控制 = 朱红，中立 = 土黄）
- **地形减速**：半透明条纹纹理（继承 L1 §2.3.4，引用真源 COMBAT-16）
- **山脉轮廓**：高度差异通过墨黑描边粗细表达（不绘制水墨笔触）

## 5. 单位模型风格

### 5.1 终版路线图（§6 第四阶段）

- **方向**：写实风格但带有"战旗/戈矛"历史考据，避免过度夸张（GDD §4.3）
- **七国变体**：基础 4 类的强化/变体（GDD §2.4 映射表）
- **装备考据**：参考战国出土文物，但**不做 1:1 还原**

### 5.2 MVP 阶段（当前，本规范约束）

- **基础几何**：占位 cube + 战旗 billboard
- **色码区分兵种**（与 L1 §8.1 共享）：

  | 兵种 | 几何 | 底色 | 边缘 |
  |---|---|---|---|
  | 枪兵/矛阵 | 竖立方块（1.0×2.0×0.3） | 土黄 | 墨黑 |
  | 轻骑 | 横立方块（0.6×0.8×2.0） | 赭石 | 墨黑 |
  | 弩兵/弓兵 | 竖立方块（1.0×2.0×0.3） | 朱红 | 墨黑 |
  | 重步 | 立方块（1.5×1.5×1.5） | 墨黑 | 土黄 |

- **七国变体**：用色相差异 + 战旗颜色区分（赵骑 = 赭石旗，秦弩 = 朱红旗）
- **移速表达**：单位底色轻微向冷/暖偏移（移速高 → 偏暖，移速低 → 偏冷）——次要视觉提示，不喧宾夺主
- **结阵表达**：单位间距缩小 + 战旗前倾（与 L1 §2.4.4 共享）

## 6. 字体

### 6.1 候选字体

| 用途 | 一选（付费） | 二选（免费） | 回退 |
|---|---|---|---|
| 标题 | 汉仪南宫体 | 思源宋体 Heavy | 系统宋体 |
| 正文 | 方正书宋 | 思源宋体 Regular | 系统宋体 |
| 数值/计时 | 方正报宋简 | 思源等宽 Regular | 系统等宽 |
| 战场标语 | 汉仪南宫体（竖排） | 思源宋体 Heavy | 系统宋体 |

### 6.2 字体应用规则

- **数值/计时器必用等宽字体**——避免数字跳变（庙钟倒计时、谋略点等必须稳定显示宽度）
- **竖排标题需字体支持**——开篇画面、仪式场景（如"赵军大营"四字）
- **简繁混排测试**——"诡道""庙算""纵横"等词不能缺字
- **商用字体需授权**——商业化前完成法务审查（暂缓项 §11）

### 7.1 核心参考（团队对齐用，不做内容照搬）

### 7.2 局部参考

| 类别 | 参考来源 |
|---|---|
| 水墨地形 | 北宋山水画（范宽《溪山行旅图》、郭熙《早春图》）——线稿与笔触方向 |
| 阵营 UI 纹样 | 战国虎符实物（陕西博物馆藏）、青铜器纹样（饕餮/夔龙简化） |

### 7.3 反例（明确应避免）

- ❌ **卡通 Q 版风格**（与历史感冲突）
- ❌ **科幻 UI**（全息/数字感与战国时代冲突）
- ❌ **写实血腥**（《天国：拯救》式近身格斗细节）——本作战斗是"战场调度"而非"近身格斗"
- ❌ **MOBA 饱和度**（《英雄联盟》式高对比 UI）——与历史氛围冲突

## 8. MVP 低保真占位规范（落地执行用）

### 8.1 单位占位（与 §5.2 共享）

- 基础 4 兵种用 cube + 色码区分（详见 §5.2 表）
- 七国变体 = 底色差异 + 战旗颜色
- 不绘制细节纹理，仅靠几何 + 颜色 + 战旗辨识

### 8.2 战旗 billboard（核心 UI 元素）

- **旗帜颜色 = 阵营**（赵 = 赭石，秦 = 朱红）
- **旗帜倾斜 = 士气**（90° = 高昂，0° = 崩溃）
- **旗帜飘动频率 = 移速**（移动时飘动加快，静止时飘动减缓）
- **旗帜识别**：真旗 = 赭石/朱红纯色；假旗 = 灰白色（与 L1 §2.2.2 衔接）

### 8.3 地形减速纹理

- 山林/沼泽/丘陵：半透明条纹纹理（与 L1 §2.3.4 共享，引用真源 COMBAT-16）
- 赵骑地形：赵方单位在该地形略过条纹（引用真源 COMBAT-06）

### 8.4 UI 假情报标记

- 假情报对象视觉与 L1 §2.2 完全一致：alpha 0.6 + 1px 灰线边缘 + 色相偏移
- 本规范不重复定义，统一以 L1 为准

## 9. 与 L1 信息层视觉规范的关系

- **L1《信息层视觉规范 v0.1》是本规范的"具体落地"之一**，重点是信息层（信任桶/可信度/假情报对象/诡道效果）。
- **本规范提供整体美术风格锚点**（调色板、字体、参考、占位规范），L1 在其约束下细化信息表达。
- **冲突仲裁**：
  - 色码冲突 → 本规范优先（整体一致性）
  - 信息可读性冲突 → L1 优先（核心循环保护）
  - 真源表/情报规格直接冲突 → 一律回真源表/情报规格

## 12. 验收标准

按本规范执行后，逐条验收：

- [ ] **A1（对应 H2）**：MVP 占位单位能让 10 名测试玩家中的 ≥7 人区分 4 兵种 + 2 阵营
- [ ] **A2**：MVP 地形条纹能让玩家目视识别减速区（继承 L1 A2）
- [ ] **A3（对应 H3）**：调色板三基色（土黄/墨黑/朱红）覆盖率 ≥80% 画面（截屏色域统计）
- [ ] **A4（对应 H1）**：玩家口述"战国感"且能描述信任桶状态（不冲突）
- [ ] **A5**：MVP 字体在简繁混排、竖排场景下不缺字
