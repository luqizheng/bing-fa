## 1. 时代背景速写（美术定调用）

- **战争形态三段叠加**：战国是"车战衰落、步兵崛起、骑兵兴起"的交汇期。"车战时代"（商晚期—春秋）刚过，战车仍在军中但已非主力；步兵成为战场主体；前 307 年赵武灵王胡服骑射后骑兵成为独立兵种。大国兵力结构如秦、楚号称"持戟百万，车千乘，骑万匹"。
- **材质过渡期**：青铜兵器处于最后也是最辉煌的巅峰（秦俑坑 4 万余件兵器几乎全为青铜），铁兵器开始出现（铁戟、铁剑、铁甲片）但未普及。**画面基调 = 青铜金色 + 髹漆黑/朱 + 皮革原色，点缀少量铁灰色**。
- **新铸青铜是金色的**：古称"吉金"，青绿色是氧化结果。战场上的戈戟剑应当是**金黄色金属**，博物馆绿锈只用于表现"古物"场景。
- **规模感**：战争规模从几千人膨胀到长平之战数十万级；指挥靠金、鼓、铃、旗（《尉缭子》：鼓之则进，金之则止，旗麾之左则左）。

## 2. 车：战车与车战

### 2.1 基本形制（考古实测，秦俑坑战车为准）

| 部位 | 形制与尺寸 | 美术要点 |
|---|---|---|
| 辕（辀） | **独辕**，长 3.70–3.96 米，前半段上扬、后段平直压于车舆下 | 单辕是中国战车最大特征，与西方双辕不同，不可画错 |
| 舆（车厢） | 横长方形，宽约 1.4 米 × 进深约 1.2 米；两侧棂格式车輢（栏杆）高约 40 厘米；前有轼（横木扶手），**后门上下** | 车厢矮而浅，乘员呈站立格斗姿态 |
| 轮 | 直径约 1.2–1.4 米（商周大轮 130–140cm，春秋约 124cm，秦 135cm）；辐条商周 18–24 根，战国增多（"三十辐共一毂"） | 大车轮 + 高重心是战车剪影的核心 |
| 毂与軎 | 车毂细长（西周实测毂长 40cm + 铜軎 13.5cm），长毂防敌车贴靠；战国轴毂间加装铁锏减摩；曾侯乙墓出土**矛状车軎**（通长 37.5cm，带攻击性） | 轴头铜軎可做装饰细节；矛状軎 = 战车"侧刃"，可作特写 |
| 衡与轭 | 辕前端横木为衡，衡上缚双轭驾马 | 轭是架在马颈上的曲木，不是套在马肩上 |

### 2.2 驾马：驷马战车

- 一车驾四马 = **驷**：中间两匹称"服"（以轭驾于辕两侧），外侧两匹称"骖"（以皮条系于车前）。
- 秦俑坑陶马实测：马身长约 2 米，通首高约 1.72 米。
- 马具：铜马衔 + 马镳（嘴角两侧）、络头（笼头）、靷、辔（缰）；马体铜饰有当卢（额头饰）、马冠、月题、铃等——**马头装饰是战车的主要"华丽度"来源**。
- 车体通体髹漆，有的绘彩（指挥车黑漆 + 几何纹）；中山国战车辕轭用错金银纹饰，王车甚至用纯金构件（"金路车"）。
- 变体：中山国小轮战车（轮径仅 0.8 米）便于山地作战——说明"战车可按地形做差异化设计"。

### 2.3 乘员分工（一车三人，站位不可错）

| 位置 | 称谓 | 职责 | 装备 |
|---|---|---|---|
| 左 | **车左 / 甲首** | 主射，一车之首 | 弓矢 |
| 中 | **御者** | 驾车 | 仅佩短剑卫体；双臂前举揽辔，身体微前倾 |
| 右 | **车右 / 戎右 / 参乘** | 主击刺、排除障碍 | 戈、戟或矛；体态雄健 |

- 将帅乘车：将居左、御居中、戎右居右（秦俑坑实证）。
- **指挥车**：通体黑漆绘几何纹，圆形华盖，悬铜钟（甬钟通高 27cm）与扁鼓（面径约 50cm）——金鼓指挥是"指挥车"的视觉签名。
- **佐车（副车）**：随将车主车之后，仅御者 + 车右两人（"虚左"，左位留给主将避险换乘）。
- **驷乘车**：四人共乘（御者 + 军吏 + 二甲士），非通例。
- 车上另插备用长兵于舆侧 = **"车之五兵"**：戈、殳、戟、酋矛、夷矛（《考工记·庐人》）。

### 2.4 车战形态（战争场面参考）

- 编制：一乘 = 车 1 辆 + 甲士 3 人 + 配属步卒（《司马法》春秋制为 72 人，战国配属减少）；十五乘为"偏"，两偏为"卒"。
- 战术：大横队一字排开，两车常呈"品"字形；交战流程为**"合"**（对驰 → 远射 → 错毂时车右以戈戟相击）→ **"回"**（掉头再冲），循环往复直至一方溃逃。
- 局限：车大体重难回转，必须结阵缓进，追击差——这正是骑兵兴起后车战衰落的原因（也是游戏中车兵若有出场应体现的"笨重感"）。

## 3. 马：骑兵与骑射

### 3.1 胡服骑射（前 307 年，赵武灵王）

- 中原建制成规模骑兵始于赵武灵王"胡服骑射"（梁启超称其为"黄帝以后第一伟人"）；此后七国相继建骑兵，骑兵与战车并列为快速机动兵种。
- **"胡服"= 上褶（短衣窄袖）+ 下裤 + 革靴 + 皮带带钩**：与中原宽袍大袖深衣形成强烈视觉对比，是赵国阵营最重要的视觉资产（详见 §7）。
- 赵骑战绩锚点：破林胡、楼烦，灭中山；李牧北破匈奴（选车千三百乘、骑万三千匹、百金之士五万、彀者十万）；阏与之战赵奢长途奔袭破秦。

### 3.2 骑乘马具（重点避坑区）

| 部件 | 战国实况 | 美术避坑 |
|---|---|---|
| 鞍 | **软垫皮鞍**：如毯状，由两个枕头状皮革垫子缝合，前后部较宽厚（巴泽雷克式，经赵传秦）；秦骑兵俑鞍即此式 | **禁止高桥马鞍**——高桥鞍南北朝以后才有 |
| 镫 | **完全没有** | **禁止马镫**——单侧镫最早见于三国东吴丁奉墓（271 年），双镫东晋十六国（4 世纪）才普及 |
| 辔衔 | 单辔头，铜衔 + 镳 | 与驾车马具同源，可共用纹样 |
| 马饰 | 当卢、络头铜饰 | 骑兵马饰远比驾车马简朴 |

- **无镫骑兵的真实战力（美术必须建立的预期）**：骑手靠双腿紧夹马腹、核心发力稳定身体；上身姿态略前倾，**不可能踩镫突刺、更不可能在马上做重冲击格斗**。战国骑兵的主战方式是**骑射袭扰**（弓），近身只能用短兵（剑）辅助；骑弓射程还不及步兵强弩，战马目标又大。因此战国至秦汉之际，**几乎没有单纯骑兵击败成建制主力步兵的战例**——典型对照就是李牧破匈奴（§5.3）。画面上骑兵的角色是：侦察、奔袭、追击、侧翼包抄与溃散收割，而不是正面冲阵的"重骑兵"。
- 秦骑兵俑姿态参考：立于鞍马左前方，一手牵缰、一手提弓（牵马待发态）；骑姿俑见秦俑坑骑兵鞍马俑。
- **骑兵在全军中的占比很低**：大国号称"车千乘、骑万匹"，相对数十万步兵，骑兵是少数精锐。李牧决战选兵约 20 万，骑兵仅 1.3 万（约 6.5%，见 §5.3）。
- 马的体量：战国军马体格小于后世挽马，肩高大致 1.35–1.45 米级（按陶马通首高 1.72 米推），**不要画成近代高头大马**。

## 4. 兵器

### 4.1 格斗长兵（步战/车战主力）

| 兵器 | 形制 | 用法与时代 | 美术要点 |
|---|---|---|---|
| **戈** | 戈头 = 援（锋刃部）+ 胡（下垂弧部）+ 内（尾部），上有穿（孔）绑柲；车战戈长约 3 米 | 钩杀、啄击，商至战国；春秋后渐被戟取代 | 戈是"勾"不是"刺"，攻击动作是横向勾啄 |
| **戟** | 戈矛合体：上刺下勾 | 直刺 + 勾啄全能，车步骑通用；战国军队第一攻击兵器（"持戟百万"）；战国出现窄长铁戟 | 战国画面里戟应是最常见的长兵 |
| **矛** | 矛头窄长带脊，圆骹装柄，柲末端铜鐓 | 直刺；文献分酋矛（步用，柄约二丈 ≈4.6 米）与夷矛（车用，二丈四尺 ≈5.5 米） | 超长矛用于方阵层层推进（§7 矛阵锚点） |
| **铍** | 形似短剑插长柄：尖锋、平脊、双刃，扁茎装柄 | 刺击，秦俑坑大量出土 | 容易被误认为"剑"，是秦军特色长兵 |
| **殳** | 竹木长柄 + 青铜殳头（棱形/矛状），打击类 | 车之五兵之一，战国渐礼仪化 | 可作仪仗、卫兵器械 |

- **柲（柄）工艺**：积竹木柲——木芯外裹竹条、缠丝髹漆，弹性好不易折；柄截面前扁后圆。长兵柄不是光杆木棍，有髹漆分节质感。

### 4.2 短兵

| 兵器 | 要点 |
|---|---|
| **青铜剑** | 中原诸国剑长一般 50–65cm；**秦剑细长柳叶形，81–94.8cm**（远超六国，秦俑坑实证）——"长剑"是秦军视觉签名。楚人尚佩剑（"长剑危冠"），楚复合剑脊韧刃硬、剑身双色；吴越为名剑之乡（越王勾践剑：长 55.7cm，菱形暗纹 + 八字铭文，出土如新） |
| **铁剑** | 战国晚期出现于燕、楚等地，长可近 1 米，数量少，可作精锐/将领特写 |
| **刀** | **战国刀不是主战兵器**（削刀、短刀为工具/卫体）；环首刀大量装备是汉代以后——**禁止给战国步骑批量配长刀**（"胡刀骑士"一类说法属通俗演绎，勿作依据） |
| **匕首** | 贴身短刃（荆轲"图穷匕见"），可作刺客、死士特写 |

### 4.3 远射

| 兵器 | 要点 |
|---|---|
| **弓** | 复合反曲角弓：干、角、筋、胶、丝、漆"六材"；箭 = 铜/铁镞 + 竹木杆 + 雕鹰羽 |
| **弩** | 战国最强单兵远射兵器，铜弩机核心部件 = **牙（挂弦）、望山（瞄准）、悬刀（扳机）**；射程远、命中高、可预张待机。张弦方式分臂张（臂力）与蹶张（脚踏腰引） |
| **强弩数据锚点** | 魏武卒"操十二石之弩"；韩国"天下之强弓劲弩皆从韩出"，谿子、少府、时力、距来诸名弩"皆射六百步之外"，韩卒"超足而射（蹶张），百发不暇止" |
| **箭镞** | 战国主流为三棱铜镞（秦俑坑实证，标准化程度高，流线型三棱无翼）；鸣镝（响箭）可用于信号特写 |

### 4.4 防护装具

**甲（皮甲为主体）**

- 形制：**札甲**——皮甲片（"札"）以丝带编缀，横排称"旅"、层数称"属"；胸背固定编缀、肩袖活动编缀；整套 = 身甲 + 甲裙 + 甲袖 + 盆领（护颈）。
- 工艺巅峰 = **曾侯乙墓皮甲胄**（战国初）：模压成型（近百套模具）、甲片髹漆（黑/朱，漆膜约 0.35mm）、露表甲片边缘压凹槽装饰；白荣金复原 13 套人甲 + 2 套马甲。
- 材质分级（《考工记》）：犀甲 / 兕甲 / 合甲（多层复合，"寿三百年"）；实战多为牛皮，犀兕属高级装备；楚地特色"鲛革犀兕以为甲"（鲨皮、犀皮，《荀子》称其"坚如金石"）。
- 铁甲：战国晚期出现（《吕氏春秋》中山勇士"衣铁甲，操铁杖"），远未普及——**画面中铁甲只给顶级精锐**。

**胄（头盔）**

- **皮胄**：曾侯乙墓式，18 片皮甲片编缀，顶部圆脊，前额片下垂护双目，两侧垂片护耳颈。
- **铁兜鍪**：燕下都 M44 出土（战国晚期），89 片铁札叶编缀、高 26cm 宽 24cm，圆形平顶 + "T"形前额——**七国中最有考古实证的铁盔**，可给燕系/精锐单位。
- **青铜胄**：商周遗制（殷墟式兽面纹铜胄），战国已少用，仅作礼仪/复古元素。
- **秦军多不戴胄**："科头"（露发髻，偏右椎髻）奋戟是秦锐士标志（《史记》"虎贲之士跿跔科头"）；秦俑即无胄、以发髻与冠饰分兵种等级——**秦军剪影 = 偏髻无盔 + 札甲**，与戴胄的六国军队形成对比。

**盾**

- 竹、木、藤、皮质，表面髹漆防潮，多施彩绘（楚式龙凤纹漆盾最精）；形制有长方形步盾、小圆盾、车用大盾（防护舆侧）。

### 4.5 指挥与阵列器物（战场氛围素材）

- **金鼓铃旗**：鼓（进）、金/钲（止退）、铃（传令）、旗（方向）；将帅麾旗 + 指挥车钟鼓。
- 旌旗：杠（旗杆）+ 旒（飘带）+ 章纹（鸟章、章纹徽记），军阵旗帜色彩与徽章是区分阵营的第一视觉手段。
- 錞于、钲、铎：青铜响器，可作战场音效/UI 图标本体。

## 5. 兵种体系与七国特色

### 5.1 通用兵种结构

| 兵种 | 定位 | 视觉签名 |
|---|---|---|
| 车兵（甲士） | 贵族/精英，冲击与指挥平台 | 驷马战车 + 长戟 + 皮甲胄；车上三人的站位分工（§2.3） |
| 骑兵 | 前 307 年后兴起，**占比小**（约 6–7%）：侦察/奔袭/侧击/追击，不承担正面冲阵 | 胡服短衣长裤 + 软垫鞍无镫 + 骑弓（§3）；无重骑兵（无马镫即无马上冲击格斗） |
| 重装步兵 | 方阵主力，披甲持戟矛 | 札甲 + 长戟/超矛 + 盾 |
| 轻装步兵 | 机动、山地、杂役 | 短甲或无甲 + 戈/剑 |
| 弩兵/弓兵 | 远射火力，可预张齐射 | 蹶张姿态（脚踏弩、腰引弦）是弩手最有戏剧性的动作 |
| 斥候/轻骑侦 | 侦察 | 轻骑减装、无旗少甲（游戏侦察单位锚点） |

### 5.2 七国精锐与风格（素材库按国别检索用）

> 正史锚点引《荀子·议兵》："齐之技击不可以遇魏氏之武卒，魏氏之武卒不可以遇秦之锐士。"

| 国 | 精锐 | 装备与风格要点 | 考据说明 |
|---|---|---|---|
| **秦** | 锐士 | 军功爵激励、单兵悍勇；科头偏髻、无胄札甲；长剑（81–94.8cm）+ 强弩 + 铍；兵马俑为最直接形象库 | 兵马俑坑 = 一手素材；"铁鹰锐士"之名出自小说《大秦帝国》，**演绎**，正史仅称"锐士" |

### 5.3 战例锚点：李牧（？—前 229）——多兵种协同与"以步制骑"的教科书

> 李牧，赵柏仁（今河北隆尧）人，与白起、王翦、廉颇并称"战国四大名将"，封武安君；两阶段生涯：北御匈奴、南抗强秦，未尝败绩。前 229 年中秦反间计被赵王迁冤杀，"李牧死，赵国亡"。本节同时是游戏**信息欺骗玩法**（示弱、佯败、诱敌、反间）最直接的历史母题。

**(1) 赵破匈奴之战（前 244 年，代郡、雁门）——步兵大兵团全歼骑兵大兵团**

- **战略隐忍（坚壁清野数年）**：军令"匈奴即入盗，急入收保，有敢捕虏者斩"；日击数牛飨士、习骑射、谨烽火、**多间谍**（情报网是其作战体系的一环）。被匈奴、边兵乃至赵王视为怯战，一度被罢官；复职条件是"王必用臣，臣如前，乃敢令"。
- **决战选兵（《史记》原文，关键比例）**："乃具**选车得千三百乘，选骑得万三千匹，百金之士五万人，彀者十万人**，悉勒习战。"总兵力约 20 万，其中：

| 兵种 | 数量 | 占比 | 战中职能 |
|---|---|---|---|
| 战车 | 1300 乘 | — | **正面列阵如墙**，阻滞、挤压匈奴骑兵冲锋，使其拥堵失速 |
| 骑兵 | 1.3 万 | 约 6.5% | 控制于阵后，**不正面冲阵**；合围后自两翼加入 |
| 百金之士（精锐步兵） | 5 万 | 25% | 两翼包抄与肉搏合围 |
| 彀者（弓弩手） | 10 万 | 50% | 车阵后轮番齐射，主杀伤来源 |

- **诱敌（欺骗链）**：大纵畜牧、人民满野 → 匈奴小入，**佯北不胜，以数千人委之**（故意弃人畜败逃）→ 单于轻敌，率十余万骑大举深入。
- **杀伤结构**：车阵当正面迟滞 → 十万弩兵箭雨主杀伤（骑弓射程不及步弩、马是大目标、步有盾）→ 步骑两翼**钳形合围**。结果：歼匈奴十余万骑，单于仅以身免；乘胜灭襜褴、破东胡、降林胡，此后十余年匈奴不敢近赵边城。
- **美术场景价值**：这是"车阵 + 弩雨 + 钳形包围"最大的历史名场面——**没有骑兵对冲**；无镫骑弓兵冲向成建制车步弩阵等于送死。网络上"钩镰枪五层阵"等说法出自现代通俗文章，**非正史，勿采用**。

**(2) 抗秦诸役——防御反击大师**

- **肥之战（前 233 年，宜安—肥下）**：秦将桓齮深入赵境。李牧沿用"先为不可胜"——筑垒固守不战；待秦军主力转攻肥下、大营空虚，**突袭秦营、焚其辎重、断其粮道**，于秦军回援途中设伏夹击，大破之（秦史罕见的惨败，桓齮败逃，一说即樊於期）。李牧因功封**武安君**。
- **番吾之战（前 232 年）**：秦军南北两路攻赵。李牧判断南路为主力，集中兵力于番吾阻击、各个击破，北路闻讯自退。
- 前 229 年秦使王翦攻赵，相持不下，秦以重金贿赵相**郭开行反间计**，赵王迁自毁长城杀李牧；三个月后邯郸城破、赵亡。苏洵《六国论》"洎牧以谗诛，邯郸为郡"即叹此事。

**(3) 对游戏美术/设计的直接启发**

- 赵军大场面的正确配方 = **少数胡服轻骑 + 车阵 + 海量弩兵与坚甲步兵**，轻骑永远在侧翼/追击镜头里，不做正面骑兵墙。
- 李牧母题可直接映射游戏核心循环：**示弱（坚壁）→ 佯败弃饵（假情报/欺骗技能）→ 预养敌方轻敌判断（信任桶预养）→ 钳形合围**；其结局"反间计杀良将"也对应情报/欺骗系统的终局风险。
- 美术资产需求提示：北方边军气质（代郡、雁门苦寒、牧猎背景）与邯郸中枢朝服应做出区别；李牧本人形象建议以"持重边帅"而非"轻骑猛将"为基调。

## 7. 与 MVP 的衔接（赵 vs 秦 · 克制环四兵种视觉锚点）

> 仅为视觉锚定，兵种数值与克制关系以《关键数值与规则真源表 v1.2》与《基础兵种数值表 v0.2》为准。

| 克制环兵种（GDD §2.4.1） | 历史视觉锚点 | 一句话造型方向 |
|---|---|---|
| 枪兵 / 矛阵 | 长矛（酋矛 ≈4.6m）+ 戟的密集方阵 | 超长枪戟林 + 札甲方阵，"墙"感 |
| 轻骑 | 赵胡服骑射（§3）；李牧战例中占比仅约 6.5%（§5.3） | 短衣长裤、软鞍无镫、骑弓回身射；**画面定位为侧翼/追击/侦察，不做正面骑兵墙** |
| 弩兵 / 弓兵 | 韩/秦强弩（蹶张十二石）+ 三棱镞 | 脚踏弩张弦的定格动作 = 最强识别帧 |
| 重步 | 魏武卒三属之甲（§5.2） | 全覆札甲（身甲+甲袖+甲裙）+ 长戟 + 盾 |

- **赵阵营**：胡服骑射是第一识别资产；步兵承中原札甲体系。
- **秦阵营**：科头偏髻无胄 + 长剑 + 强弩（兵马俑直接素材库）。
- 战车与车兵在战国中期已非主力，MVP 若出场宜作**指挥/仪式性单位**（华盖钟鼓指挥车），避免喧宾夺主。

### 美术避坑清单（时代硬伤，优先级最高）

1. **禁止马镫**（双镫 4 世纪才普及）、禁止高桥马鞍。
2. **禁止重骑兵化**：无镫骑兵不能正面冲击步兵阵，不持长槊突刺、不人马具甲；战国骑兵 = 轻装骑射，主役是侦察/袭扰/侧击/追击（李牧 20 万选兵中骑兵仅 1.3 万）。
3. **禁止步骑批量配长刀**（环首刀是汉代装备）；战国主战短兵是剑。
4. **禁止板甲、锁子甲、鱼鳞甲普及**——札甲是唯一主流；彩色鱼鳞甲仅秦将军俑级。
5. **秦军不画头盔**（科头奋戟）；六国可用皮胄/燕式铁兜鍪。
6. 马画小不画大（肩高约 1.4m 级）；战车单辕四马、乘员左射中御右击。
7. 青铜兵器画金色不画绿锈；髹漆黑朱为主色。
8. 战阵指挥画金鼓旗麾，不画号（唢呐/号角皆后世）。
