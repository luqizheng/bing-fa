## 一、游戏概述

### 1.1 核心概念

> "兵者，诡道也。故能而示之不能，用而示之不用。"

《战国·兵者诡道》是一款以中国战国时期（公元前 5–3 世纪）为背景的即时战略游戏。玩家扮演七国之一的君主或统帅，通过军事欺骗、地形利用、外交纵横来击败对手，最终统一天下。

**核心创新点：**

1. **信息不对称战争**：没有"战争迷雾"的绝对去除，所有信息依赖斥候侦查，虚假情报与真实情报并存。
2. **三十六计即插即用**：每个阵营和幕僚拥有独立的"诡道技能"，相互克制。
3. **历史沉浸式叙事**：动态事件 AI 根据玩家行为生成历史"如果"推演。

### 1.2 核心体验目标

| 玩家群体 | 目标体验 |
|---|---|
| RTS 老玩家 | 通过复杂计谋和微操，以弱胜强的智力快感 |
| 历史爱好者 | 沉浸式体验战国"合纵连横"的权谋感 |
| 策略入门玩家 | 通过幕僚 AI 辅助，逐步理解多层次战略决策 |
| 剧情/叙事玩家 | 动态历史事件，每一局都是独一无二的"平行战国" |

### 1.3 玩法概括（30 秒电梯演讲）

> "你扮演战国七雄之一的君主。你不仅要建造军队、采集资源，更要用'减灶'欺骗敌人、用'声东击西'调动敌军、用'反间计'收买对手——你的每一个'诡道'技能都可能决定战局。同时，你的幕僚会给你建议，但最终决策权在你手中。这场战争，赢家不是兵力最多的人，而是最会骗人的人。"

## 二、核心玩法机制

### 2.1 游戏循环

```text
【庙算阶段】→【外交·情报·布局】→【战役阶段（RTS 实时）】→【战后评估】→【历史叙事触发】→【循环】
```

- **庙算阶段**：每场战役前，玩家进行外交、间谍派遣、谋略规划（非实时，类似回合制决策面板）。
- **战役阶段**：核心 RTS 玩法，玩家实时操控军队，释放"诡道"技能，侦查与反侦查交替进行。
- **历史叙事**：根据关键事件（斩首名将、焚毁粮道、失守都城）触发剧情分支，改变游戏走向。

### 2.2 资源系统

| 资源名称 | 用途 | 获取方式 |
|---|---|---|
| 粮草 | 维持军队生存（每日消耗），攻城战核心 | 农田、商道、缴获敌军 |
| 铁器/青铜 | 生产武器、盔甲、攻城器械 | 矿山、冶铁坊 |
| 战马 | 生产骑兵，提升机动性 | 牧场（赵国优势）、缴获胡马 |
| 金/布帛 | 外交、收买间谍、雇佣军 | 关税、贸易、掠夺 |
| 谋略点 | 释放"诡道"技能 | 每回合自动恢复，或通过"情报"行为获取 |

### 2.3 诡道技能系统（核心亮点）

每个阵营和幕僚拥有独立的"诡道技能树"。技能分三类：

| 类型 | 描述 | 示例 |
|---|---|---|
| 欺骗类 | 制造假情报，误导敌人 | 增灶示强、减灶示弱、伪传军令 |
| 突袭类 | 出其不意，破坏敌方部署 | 暗度陈仓、火攻粮道、断粮道 |
| 外交类 | 利用外部力量影响战场 | 合纵连横、反间计、借刀杀人 |

**技能示例（以本次推演中使用的技能）：**

| 技能名称 | 所属阵营/幕僚 | 效果 | 冷却/消耗 |
|---|---|---|---|
| 减灶示弱 | 赵国（通用） | 降低敌方对你兵力的评估，引诱对手轻兵冒进 | 1 回合 / 30 谋略点 |
| 烽火疑兵 | 秦国（白起专属） | 制造多个"主力位置"假象，分散敌方侦查 | 2 回合 / 50 谋略点 |
| 焚粮断道 | 赵国（赵王亲率） | 摧毁敌方粮草供应，令其饥饿度上升 | 全局仅一次 / 80 谋略点 |
| 合纵连横 | 外交（苏代专属） | 临时拉拢第三方阵营加入战斗 | 3 回合 / 60 谋略点 |
| 暗度陈仓 | 通用 | 使步兵单位穿越不可通行的山地，突袭后方 | 1 回合 / 40 谋略点 |

### 2.4 兵种系统与克制关系

**七国特色兵种矩阵：**

| 国家 | 特色兵种 | 优势 | 劣势 | 诡道加成 |
|---|---|---|---|---|
| 秦 | 锐士（重步） | 高攻高防，阵型稳固 | 速度慢，粮草消耗大 | "军功爵位"越战越强 |
| 赵 | 胡服骑射（轻骑） | 机动性 + 移速射击，忽略地形减速 | 攻城弱，护甲薄 | "骑射脱兔"侧翼打击加成 |
| 楚 | 巨弩楼船/水军 | 沿河视野 + 射程翻倍 | 内陆战乏力 | "江汉天险"水域隐蔽 |
| 齐 | 技击之士（精锐散兵） | 单兵作战强，适合偷袭 | 结阵差，士气波动大 | "商道渗透"金钱策反 |
| 魏 | 武卒（重装步兵） | 免疫骑兵冲锋，不可击退 | 移速极慢，需列阵 | "重甲列阵"隘口无敌 |
| 韩 | 劲弩（远程） | 射程覆盖全屏 1/3 | 装填慢，近战脆弱 | "弩阵齐射"覆盖压制 |
| 燕 | 辽东铁骑/山戎 | 冬季视野 + 士气加成 | 春夏季战力下降 | "北境寒潮"冬季地图加成 |

**基础兵种克制：**

```text
轻骑 →（克制）→ 弩兵 →（克制）→ 重步 →（克制）→ 枪兵 →（克制）→ 轻骑
（形成循环克制，符合古战逻辑）
```

## 三、AI 系统设计

### 3.1 对手 AI（敌方君主/将领）

**核心架构：**

```text
情报模块（侦查/反侦查）
    ↓
信任度系统（评估情报真伪）
    ↓
目标优先级矩阵（动态调整获胜条件）
    ↓
决策树/行为树（执行战术）
    ↓
适应模块（学习玩家行为模式）
```

**关键 AI 行为逻辑：**

| AI 行为 | 触发条件 | 玩家可干扰手段 |
|---|---|---|
| 大规模进攻 | 玩家兵力评估低于 AI 40% | 减灶示弱诱导 |
| 撤退保存 | AI 粮草 < 3 日消耗 | 断粮道/焚粮 |
| 合纵求援 | AI 面临多线作战 | 反间计破坏盟友信任 |
| 设伏反击 | AI 判断你即将袭击粮道/大帐 | 利用幕僚"谨慎建议"识别伏兵 |

### 3.2 幕僚 AI（玩家参谋）

**性格参数系统：**

每个幕僚拥有以下多维评分系统：

| 幕僚 | 进攻性 | 谨慎度 | 外交倾向 | 奇谋倾向 | 风险承受力 |
|---|---|---|---|---|---|
| 赵括 | 9 | 2 | 3 | 9 | 8 |
| 廉颇 | 4 | 9 | 4 | 3 | 2 |
| 苏代 | 3 | 6 | 9 | 8 | 5 |

**交互形式：**

- 每次决策前，点击幕僚头像可查看其建议（显示为古文/白话文字框）。
- 幕僚之间可能互相辩论（UI 上显示为对话气泡）。
- 随着玩家采纳建议的胜败，幕僚的"信任度"动态变化（采纳建议且胜利 → 信任度↑；采纳建议且失败 → 信任度↓，该幕僚未来的建议会更保守或更激进）。

### 3.3 历史叙事 AI（动态事件生成器）

**条件触发事件树（简化示例）：**

```text
事件：玩家斩首白起
    ↓ 条件检查（是否真实斩杀或俘虏？）
    ↓
分支 A（成功）：
    → 秦国朝野震动，秦昭襄王增兵复仇
    → 触发新事件："秦赵全面战争"
    → 地图扩展至三晋全部领土

分支 B（失败/未触发）：
    → 白起继续担任秦将
    → 触发事件："白起之恨"（未来战役白起 AI 获得 20% 攻击加成）
    → 玩家可触发新选择："密谋暗杀白起"或"离间秦廷"
```

### 4.2 核心交互流程

**1. 侦查操作：**

- 点击"斥候"单位 → 划定侦查区域 → 一定时间后返回情报。
- 情报以"可信度"标注显示（高/中/低）。

**2. 释放诡道技能：**

- 选择技能图标 → 目标区域/单位 → 消耗谋略点 → 技能生效。
- 技能效果以视觉特效呈现（如"减灶"显示炊烟减少的粒子效果）。

**3. 幕僚建议调用：**

- 按 T（赵括）、L（廉颇）、S（苏代）快速查看建议。
- 或点击 UI 左下角幕僚头像。

### 4.3 视觉风格

- **整体色调**：仿古帛画/竹简质感，土黄、墨黑、朱红为主色。
- **UI 元素**：以"竹简展开""虎符""青铜纹"为设计元素。
- **地图风格**：水墨风格地形图，山脉以中国传统山水画表现。
- **部队模型**：写实风格但带有"战旗/戈矛"历史考据，避免过度夸张。

### 5.2 AI 核心算法

**信任度系统（伪代码）：**

```csharp
public class AITrustSystem {
    private float trustLevel = 0.5f; // 0~1
    private int consistentReports = 0;

    public bool EvaluateIntel(Report report) {
        if (report.ConsistencyWithPrevious) {
            consistentReports++;
        } else {
            consistentReports = Mathf.Max(0, consistentReports - 2);
        }

        trustLevel = Mathf.Clamp(consistentReports * 0.1f, 0.2f, 0.9f);

        if (trustLevel > 0.7f) {
            return true; // 相信情报
        } else if (trustLevel < 0.3f) {
            return false; // 怀疑情报，AI 会投入更多斥候验证
        } else {
            return Random.Range(0f, 1f) < 0.5f; // 半信半疑
        }
    }
}
```

**目标优先级动态调整：**

```csharp
public class AIGoalSystem {
    private List<Goal> goals = new List<Goal>();

    public void UpdateGoals(CurrentState state) {
        foreach (var goal in goals) {
            float successRate = goal.Evaluate(state);
            float urgency = goal.GetUrgency(state);
            goal.Priority = successRate * urgency;
        }
        goals.Sort((a, b) => b.Priority.CompareTo(a.Priority));
        ExecuteTopGoal();
    }
}
```

## 八、附录：本次推演中的 AI 数据回溯

以下数据来自本次推演中运行的白起 AI 行为记录，用于展示 AI 系统的实际运行逻辑：

| 时间节点 | AI 决策 | 触发因素 | 玩家欺骗手段 | AI 信任度变化 |
|---|---|---|---|---|
| 第 1 回合 | 部署滏口伏兵 | 玩家"减灶"成功，AI 初步相信西线空虚 | 减灶示弱 | 50% → 60% |
| 第 3 回合 | 白仲疑兵驻留 | AI 发现"减灶"是假，开始怀疑 | 赵括佯攻北线 | 60% → 40% |
| 第 4 回合 | 白起改攻上党 | AI 判断滏口难取，转换目标 | 赵王分兵佯攻 | 40% → 50% |
| 第 5 回合 | 高都高地设伏 | AI 预判斩首行动，反向设伏 | 赵王焚粮后直取中军 | 50% → 90% |
| 第 6 回合 | 提出"活捉换俘" | AI 评估活捉价值 > 杀死价值 | 赵王亲自攀山突袭 | 90% → 85% |

> **结论：** 白起 AI 始终在动态调整策略，玩家每次成功欺骗都会短期收益，但若被识破则 AI 会迅速反击——符合"兵者诡道"的核心精神。

## 九、最终结论与建议

### 9.1 项目可行性评估

| 维度 | 评分（1–10） | 理由 |
|---|---|---|
| 玩法创新性 | 9 | R.U.S.E. 框架 + 三十六计融合，国内市场独特性 |
| 技术实现难度 | 7 | AI 系统复杂但现有技术可支撑（ML-Agents + 行为树） |
| 历史考据成本 | 6 | 需历史顾问，但已有大量可参考史料 |
| 市场受众 | 8 | RTS 玩家 + 历史爱好者 + 策略玩家，三圈覆盖 |
| 商业模式成熟度 | 7 | 买断 + DLC 模式验证过，创意工坊可延长生命周期 |

### 9.2 第一版开发建议（MVP 最小可行产品）

**优先实现：**

- 赵国与秦国两个完整阵营
- 3 个核心诡道技能（减灶、增灶、火攻）
- 一个完整的战役剧本（"太行山保卫战"，即本次推演内容）
- 幕僚 AI（至少廉颇 + 赵括两个建议系统）
- 一张地图（滏口陉–野王–高都三区域）

**延迟实现（后续迭代）：**

- 七国全部阵营（先做赵秦，再扩展）
- 36 计全部技能（先做 12 个核心）
- 历史叙事 AI 全部事件（先做主线分支）
