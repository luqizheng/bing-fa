## 3. 克制关系验算（正常士气，士气系数 = 1.0）

伤害公式：`D = max(1, 攻击 × 克制系数 − 防御)`；TTK = 生命 ÷ (D × 攻速)。

| 攻方 → 守方 | 攻击×系数 | 减防后 D | 击杀/队所需时间 |
| --- | --- | --- | --- |
| 枪兵 → 轻骑（克） | 12×1.35=16.2 | 11.2 | **8.9s** |
| 轻骑 → 枪兵（被克） | 14×0.75=10.5 | 2.5 | 48.0s（骑兵撞矛阵基本白给） |
| 轻骑 → 弩兵（克） | 14×1.35=18.9 | 15.9 | **4.4s**（弩手被骑脸速死） |
| 弩兵 → 轻骑（被克） | 16×0.75=12 | 7（远程） | 35.7s，且近身后被 4.4s 反杀 |
| 弩兵 → 重步（克） | 16×1.35=21.6 | 9.6（远程） | 41.7s；接战前可射 3–4 轮（180m ÷ 2.8m/s ≈ 64s 接近时间，弩手约射 25 发 = 240 伤害，可在接触前击溃） |
| 重步 → 弩兵（被克远程侧） | 接触后 10×0.75=7.5 | 4.5 | 19.4s |
| 重步 → 枪兵（克，冲静止矛阵） | 10×1.35=13.5 | 5.5 | 27.3s |
| 枪兵 → 重步（被克） | 12×0.75=9 | max(1, 9−12)=**1** | 120s（保底 1 伤害生效，枪兵打不动重步） |
| 同类型对砍 | ×1.00 | — | 枪 12–30s / 骑 11.1s / 弩接触后 5.4s / 重步 80s |

验算结论：① 克制环四个箭头全部成立且手感差异显著（4.4s 速杀 vs 48–120s 刮痧）；② max(1) 保底在"枪兵打重步"时实际触发，数值有效；③ 弩兵的价值窗口在接敌前的 60 秒远程区，符合"射程射杀重甲、被骑脸即死"；④ 单场接战 5–40 秒、多队交战可支撑 15–20 分钟局时长（TIME-04）。

### 3.1 地形减速系数与赵骑地形验算（v0.2 新增，COMBAT-16）

切片地图"太行山·滏口陉"以山林/丘陵（**减速通行**）为主体，地形系数不能再留空。先定一项全局初值：

| 地形 | 移速修正 | 受影响单位 |
| --- | --- | --- |
| 减速通行（山林/沼泽/丘陵） | 移速 **×0.6【初值】** | 除赵胡服骑射外全部单位（COMBAT-06：赵骑忽略减速） |
| 可通行（平原/官道） | ×1.0 | 全部 |
| 不可通行 | — | 全部（暗度陈仓限时例外，切片不实现） |

> 地形对弩兵射程、枪兵防御等其余修正仍留 v0.3；本节只验算切片最关键的"赵骑地形风筝"风险。

减速地形内移速：

| 单位 | 平原移速 | 减速地形内移速 | 赵骑相对速度差 |
| --- | --- | --- | --- |
| 枪兵 | 3.5 | 2.1 | 赵骑 7.5 为其 **3.6 倍** |
| 弩兵 | 3.5 | 2.1 | 3.6 倍 |
| 轻骑（白板） | 7.0 | 4.2 | 1.8 倍 |
| 赵胡服骑射 | 7.5 | **7.5（忽略减速）** | — |

**风筝风险验算（赵骑骑射 12 攻 / 0.5 攻速 / 150 射程，减速地形内）：**

| 交战 | 计算 | 结论 |
| --- | --- | --- |
| 赵骑 → 弩兵（克制，弩兵无近战反制窗口） | 同 §3：4.4s 速杀，且地形把赵骑的 4.3 倍速差（平原 2.1 倍）进一步拉大 | 弩兵在减速地形里**完全无法脱离骑射**，这是"轻骑克弩兵"的强化而非失衡——弩兵本就需要枪兵保护 |
| 赵骑 → 枪兵（被克 ×0.75） | D = max(1, 12×0.75 − 8) = 1；DPS = 1×0.5 = 0.5；TTK = 120÷0.5 = **240s** | 枪兵仍无法被赵骑 solo 击杀，**克制环在减速地形内不被翻转** |
| 枪兵 → 赵骑（克制 ×1.35，需贴身） | 赵骑 7.5 vs 枪兵 2.1，枪兵无法强制接战 | 赵骑可无伤持续输出 0.5 DPS——威胁不在击杀，而在**无限白嫖与黏住** |

**结论与切片 QA 观察点：** ×0.6 下赵骑不能在减速地形 solo 吃掉枪兵（240s 超出单局时长），克制环数学上成立；真正的风险是赵骑利用 3.6 倍速差对行进中的枪兵/弩兵编队做无损骚扰、以及在滏口陉隘口两侧反复拉扯。切片 QA（SLICE-05）需专项观察：①赵骑是否让非弩兵单位在减速地形寸步难行（若是，下调忽略减速为"×0.6 地形内 ×0.8"或在密林加入骑兵不可穿越小格）；②150 射程在隘口地图是否跨地形覆盖过大。该系数与赵骑被动均为【初值】，允许在切片内直接调整后回写 COMBAT-16。

> **【v1.2 已定】** 枪兵结阵反骑（真源 COMBAT-17）：结阵枪兵移速 −20%、免疫骑兵冲锋击退、拒马反噬（骑兵骑射结阵枪兵时自身承伤 6 点/发）。赵骑"无伤白嫖枪兵"从"无成本"变为"有成本"（赵骑骑射 0.5 攻速 → 反噬 3.0 DPS → 100 血约 33s 自毙），本节识别的"赵骑无伤骚扰"风险被对冲，切片 QA 观察点从"是否失衡"转为"反噬是否过强"。

### 3.2 壁垒线（工事）防御系数（v0.3 新增，COMBAT-18）

长平地图的"百里石长城壁垒线"是**工事**而非地形减速带，其规则与 COMBAT-16 的减速系数分离，单独由真源 COMBAT-18 承载：

| 项 | 值 | 说明 |
| --- | --- | --- |
| 非缺口段通行 | 不可通行 | 全单位（含赵胡服骑射）——COMBAT-06 的"忽略减速"对**不可通行**不适用 |
| 缺口/故关段通行 | 可通行 | 宽度见真源 MAP-12（约 16m 缺口） |
| 守方防御力 | **+25%【初值】** | 仅对**壁垒线所属方**在缺口段生效；攻方不享受 |
| 冲锋击退 | 守方免疫 | 与 COMBAT-17 结阵效果叠加时取其一，不重复计算 |
| 可破坏性 | 不可破坏 | 切片不做攻城；归属随 GDD §2.7.1 据点判定转移 |

**TTK 影响验算（守方 +25% 防御，正常士气，士气系数 1.0）：**

| 攻方 → 守方（守方在缺口段） | 原 D（无工事） | +25% 防御后 D | TTK 变化 |
| --- | --- | --- | --- |
| 重步 → 枪兵（克制 ×1.35） | 10×1.35−8 = 5.5 | 10×1.35−10 = 3.5 | 120÷3.5 ≈ **34.3s**（原 21.8s） |
| 秦锐士 → 枪兵（克制 ×1.35） | 12×1.35−8 = 8.2 | 12×1.35−10 = 6.2 | 120÷6.2 ≈ **19.4s** |
| 轻骑 → 枪兵（被克 ×0.75） | max(1, 10.5−8) = 2.5 | max(1, 10.5−10) = **1（保底生效）** | 120÷1 = **120s**（保底伤害接管） |
| 枪兵 → 枪兵（同类型） | max(1, 12−8) = 4 | max(1, 12−10) = 2 | 120÷2 = **60s** |

**结论与切片 QA 观察点：** +25% 防御让"正面强攻故关"的代价显著上升（重步 TTK 从 21.8s 升至 34.3s，轻骑直接落到保底伤害），符合地图设计稿 G2"壁垒逼出欺骗而非堆兵"的设计意图；但若实测发现**进攻方在 20 分钟硬上限内根本无法突破缺口**，则应下调至 +15%，或允许火攻（SKILL-03）对缺口段守军造成额外压制。该系数为【初值】，允许在切片内直接调整后回写真源 COMBAT-18。

> **注意**：本条**不改变** COMBAT-16 的减速 ×0.6，也不为山头（韩王山/大粮山）设任何射程或防御加成——那些仍待《基础兵种数值表 v0.4》。

## 4. 士气系数（与 COMBAT-09 对齐，补入真源）

伤害公式中的士气系数：高昂（≥80）×1.0；正常（50–79）×1.0；动摇（20–49）×0.8；崩溃（<20）单位不再正常作战（溃逃中）。

> 说明：高昂档的"攻击 +10%"是**面板攻击加成**（COMBAT-09），不再乘进士气系数，避免与 ×1.0 双重表述；即高昂伤害 = `攻击×1.1×克制−防御`。动摇的 −20% 攻击走同一面板口径。实现时统一为面板修正，士气系数在正常/动摇两档取 1.0/0.8。
