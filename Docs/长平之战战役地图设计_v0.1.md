## 1. 为什么主战场是长平（与滏口陉的分工）

滏口陉稿解决的是"选一张能验证欺骗的地图"；长平主战场解决的是"把史实戏剧性装进可玩的一局"。

1. **信息不对称的教科书案例**：廉颇坚壁不出 → 秦军挑战无效 → 范雎反间换将 → 赵括出击 → 白起佯败诱敌、奇兵绝后路、骑兵割裂壁垒 → 断粮 46 日。**欺骗的每个环节在史书里都有对应动作**，不需要硬塞。
2. **双向可骗且不对称**：赵可减灶示弱诱秦军脱离壁垒；秦可减灶示弱诱赵括全力追击、并以增灶示强掩盖合围兵力。三个 MVP 诡道在本图双方各自都有自然落点。
3. **地形天然制造信息差**：丹河两岸对峙 + 壁垒线遮挡 + 两翼山地，逼出"斥候必须过河/上山才能清点"的结构，直接复用 DECP-04 近距 50 米清点机制（河谷宽度足以让远观与清点结果分叉）。
4. **饥困是可玩的慢变量**：本图第一次让 FOOD-04 的三档饥饿成为**主线机制**（第 ⑥ 幕的唯一压力源），而非边角料。
5. **范围收敛**：仍是一张图、两个阵营、三个诡道；七幕是同一张图上的不同态势，不是七张地图，实现面可控。

## 2. 设计目标

| 编号 | 目标 | 验收方式 |
|---|---|---|
| G1 | 地图必须让"侦查→欺骗→识破/采信"循环在**每一幕**至少发生一次，且全战役至少完整跑通一次含桶预养的减灶链路 | §11 A1 |
| G2 | 西垒（壁垒线）为赵方防守优势位：正面强攻代价明显高于用假情报调动守军 | 强攻 vs 诱敌的战损/耗时对比 |
| G3 | 丹水渡口是唯一补给咽喉，切断后 FOOD-06 生效、饥饿在 3 分钟内可感知 | §11 A3 |
| G4 | 两翼山地要真正"绝后路"：秦军奇兵路线必须存在且斥候覆盖不足时不易被发现 | 第 ⑤ 幕合围成功率与发现率 |
| G5 | 全图无"必须读敌方真值"才能玩的点位（NET-02） | 认知查询只走情报池的代码审查 |
| G6 | 赵骑（赵胡服骑射）在两翼山地可风筝，但结阵枪兵（COMBAT-17）在壁垒缺口前可反制 | 对齐兵种表 v0.3 §3.1 QA 观察点 |

战役沿**丹河南北向河谷**展开：秦军自南（野王方向）沿河谷北上，赵军据**北岸西垒**凭百里石长城壁垒线固守；丹水渡口是连接南北的唯一补给咽喉；两翼为韩王山（西）、大粮山（东）山地，是秦军奇兵绕行与赵军粮道所在。

## 7. 双方部署（第 ① 幕开局态势）

| 项 | 赵（玩家默认） | 秦（AI） |
|---|---|---|
| 出生区域 | 西垒后（北侧） | 东垒（南侧，光狼城一带） |
| 初始占据 | 西垒壁垒线 + 故关（开局赵先占） | 东垒平地 + 光狼城 |
| 补给方向 | 大粮山粮仓 → 壁垒线 | 光狼城粮仓 → 丹水渡口 → 壁垒线 |
| 携粮 | 每队 3 日粮 = 18 战场分钟（FOOD-01） | 同左 |
| 消耗 | 每 60 秒 1 单位（FOOD-02）；断粮走 FOOD-04 | 同左 |
| 默认画像 | 玩家自由 | 白起：高欺骗倾向，劣势时 AI 欺骗 ×0.7 倍率（AI-05），主动减灶诱赵括式冒进 |
| 幕僚 | 廉颇（前 ①②③ 幕，建议"坚守勿出"）→ 赵括（第 ③ 幕后接任） | 白起（第 ⑤ 幕才"登场"，其前为假称王龁——叙事层欺骗，非机制） |

**不对称设计意图**：赵凭壁垒以逸待劳，但粮道长达大粮山、且被换将后被迫进攻；秦有平地展开与渡口控制权，但补给线单一、两翼山地迟滞。胜负手在"骗对方离开有利地形"，而非正面堆兵。

## 8. 三个诡道在本地图的落点

| 技能 | 赵方用法 | 秦方（AI）用法 | 地图配合点 |
|---|---|---|---|
| **减灶示弱**（SKILL-01/DECP-02） | 在壁垒后减灶佯作粮尽兵弱，诱秦军强攻故关撞结阵枪兵 | 在东垒/渡口减灶佯作退兵，诱赵括出垒追击、脱离壁垒 | 营盘炊烟点 + 山谷遮挡：远观只能看烟，近 50 米才能清点（DECP-04） |
| **增灶示强**（SKILL-02/DECP-03） | 在故关增灶虚张守军规模，吓阻秦军正面强攻 | 在光狼城增灶示强，掩盖合围兵力调动（第 ⑤ 幕） | 炊烟远观估算 ×1.5，靠烟柱数量/高度传达（视觉规范 §2.4.2） |
| **火攻**（SKILL-03） | 火封故关缺口断秦军前锋，或火丹水渡口/秦粮仓 | 火赵军出垒部队、火大粮山粮仓逼赵放弃壁垒 | 渡口与粮仓是 40% 毁粮目标；起火浓烟生成 75% 不可伪造 `skill_reveal` 情报（SLICE-03⑤） |
| 焚粮断道（SKILL-06/FOOD-05） | 全局仅一次：直取秦光狼城囤积点 +30% 饥饿 | AI 对等威胁大粮山 | 与火攻区分：火攻按 CD 多次、焚粮全局一次 |

> 谋略点经济、CD、施计窗口 90 秒、痕迹存续 10 分钟、不叠加刷新（DECP-08）全部按真源执行，本图不改动。

## 9. 情报战节拍与信任桶主题（按幕编排）

| 幕（见真源 CP-01…08） | 玩家动作 | 情报/欺骗事件 | AI 信任桶主题（TRUST-09，无方向载荷采信度） |
|---|---|---|---|
| ① 开局对峙（0–3 分钟） | 斥候散出（INTEL-01 基值 65%） | 渡口、故关、两翼多为"未知/可疑"（视觉规范 §2.3） | 桶自 0.50 起：`秦军_渡口守备`、`秦军_主力方向`、`赵军_出垒意图` |
| ② 挑战与拒战（3–7 分钟） | 保持壁垒不出 | 秦军斥候多次目击赵军不出垒 → 桶向"赵军固守"载荷收敛 | 同上；此为**桶预养期**：真实载荷被反复确认 |
| ③ 反间换将（战略层旬，非实时） | 收到换将事件；廉颇去、赵括来 | 剧本事件注入"秦军畏赵括"载荷（不进技能系统，见计划 §5.1） | 赵军侧：新幕僚建议语气转为激进（TRUST-10/12 性格偏移） |
| ④ 赵军出垒（7–12 分钟） | 赵括催战、玩家被迫/选择进攻 | 秦军减灶示弱（AI-05②）→ 远观赵军以为"秦军退" | `赵军_出垒意图` 桶被预养后接受"追击有利"载荷 |
| ⑤ 合围成形（12–16 分钟） | 斥候可能发现两翼奇兵（与否取决于覆盖） | 秦军增灶示强掩盖调兵；奇兵走韩王山/大粮山绝后路 | `秦军_主力方向` 桶被示强载荷占据 → 误判主攻方向 |
| ⑥ 断粮围困（战略层压缩 + 实时突围准备） | 渡口失守 → 补给判定失败 | FOOD-06 触发；饥饿三档爬升 | TRUST-11：AI 若因受骗遭重大损失 → 该主题桶 ×0.5 |
| ⑦ 突围（16–20 分钟） | 赵军择向突围 | 识破与反识破的最后一轮 | 结局判定 |

**幕僚语气（本图首次实装）**：廉颇在 `赵军_出垒意图` 桶低采信/存疑时提示"坚守勿出"；赵括在"秦军虚弱"载荷被采信后催促出击——用真实历史结局引导玩家理解"桶预养 → 载荷反转"（TRUST-10/12）。
